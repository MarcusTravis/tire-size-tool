Privacy

This site has no accounts, no ads, no cookies and no third-party trackers.

All calculations happen in your browser. The sizes you type are never sent anywhere; they only appear in the page address so you can share a link.

To see how many people use the site, it uses Cloudflare Web Analytics, which counts page views and load performance without cookies or fingerprinting. The site is hosted on Cloudflare Pages, which keeps standard server logs.

The source code is public on GitHub.
